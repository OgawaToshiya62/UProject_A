＊このリポジトリについて

このプロジェクトは、Udemy 講座「Unreal Engine5 C++：Advanced Action RPG（講師 Vince Petrelli）」 
で使用された学習用コードをベースにしています。

理解が不十分な部分もありましたが、
処理の意図を自分の言葉で整理するために全てのクラス・関数にコメントを追加しながら学習を進めました。

講座のコードをそのまま公開するのではなく、
学習過程と理解の深さを示すことを目的として公開しています。


＊講座プロジェクトのナイアガラエフェクトについて＊

今回の動画は、Udemyの講座で制作したプロジェクトの動作確認を目的として撮影しています。

講座の進行中にプロジェクト設定や参照パスが変わった影響で、
ナイアガラエフェクトが正常に表示されていません。

このプロジェクトは講座内容を理解し最後まで完成させることを目的としているため、
エフェクトの再設定は優先度を下げています。

そのため、動画ではキャラクター操作や講座で実装した機能の動作確認を中心に収録しています。
